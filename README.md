# Amigo Secreto

Projeto simples em JavaScript para sorteio de Amigo Secreto.

## Funcionalidades
- Adicionar participantes
- Listar nomes inseridos
- Sortear aleatoriamente

## Tecnologias
- HTML
- CSS
- JavaScript

## Objetivo
Praticar lógica de programação, uso de arrays, funções e manipulação do DOM.
